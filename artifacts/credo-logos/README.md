# კრედოს და დაყავის ლოგოები

ორიგინალები უცვლელია; ეს ფაილები ჯერ ჩექაუთში არ არის დამატებული.

SVG-ებში შენარჩუნებულია ორიგინალის კონტურები. ასოები ვექტორული გზებია და
მომხმარებლის კომპიუტერზე კონკრეტული შრიფტის არსებობას არ მოითხოვს.
ფონი გამჭვირვალეა. ფაილებში არ არის ჩასმული PNG/JPEG, სკრიპტი ან გარე რესურსი.

კრედოს PDF შეიცავს CMYK რადიალურ გრადიენტს. SVG-სთვის ის გადატანილია
მშობლიური რადიალური გრადიენტით, ორიგინალის მდებარეობისა და ფერის ფუნქციის
მიხედვით 259 RGB საკონტროლო წერტილით. გრადიენტი ბიტმაპად არ არის ჩასმული.
ვიზუალურად შემოწმებულია ბრაუზერის მიერ დარენდერებული SVG-ები და PNG გადახედვები.
PNG-ები წინასწარი ნახვისთვისაა; საიტზე გამოსაყენებელი ორიგინალებია SVG-ები.

„დაყავი.pdf“ და „დაყავი (2).pdf“ ბაიტობრივად იდენტურია.
„დაყავის“ ერთ PDF გვერდზე ორი ნიშანია განლაგებული; გამოყოფილია ზედა ნიშანი,
შენარჩუნებული საკუთარი ფერებითა და თეთრი კონტურებით. შავი დიდი მართკუთხედი
საპრეზენტაციო ფონი იყო და SVG-ში არ არის გადატანილი.

წყაროების სახელები, SHA-256 და გამოყოფის საზღვრები ინახება [sources.json](sources.json)-ში.
